задача создать программу которая работает с книгами.

данные хранятся в текст формате.
программа должна уметь:
1. Показывать все книги
2. Добавлять новую книгу
3. Искать книгу по названию
4. Удалять книгу
5. Выходить

Формат книги txt
каждая строка - одна книга.
данные хранять в виде название|Автор|Год|Статус|

требования по структуре кода
1.   функции: load_books(), save_books(books),display_books(books),del_book(), main()
2. Логика в меню в цикле While, прога запускается и показывает - >
    1. Показать все книги
    2. Добавить книгу
    3. Найти книгу
    4. Удалить книгу
    5. Выйти
    Выберите действие:

Добавление: запрашиваешь у юзера Название, Автора, год. статус автоматов - В наличии
Поиск: По части слова или целиком, регист не мешает поиску.

Удаление: показать весь список книг с номерами, пользователь вводит номер книги. Книгу удаляем.

Выход: Программа прощается и завершается
